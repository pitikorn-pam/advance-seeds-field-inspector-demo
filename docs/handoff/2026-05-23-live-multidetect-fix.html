Live Multi-Detect Fix

iOS Field Inspector App · ทีม Advance Seeds Field Inspector · 2026-05-23

สรุป: Live camera preview ตรวจกล้วยได้แค่ลูกเดียว แม้ในเฟรมจะมี 5 ลูก. ภาพถ่าย (snapshot) ของฉากเดียวกันตรวจได้ครบ. แก้แล้ว — บัคอยู่ใน native iOS code (Apple CoreML library อ่าน memory ผิดวิธี). ตอนนี้ live ตรวจได้ครบ 3-5 ลูกพร้อมกัน. รอ rebuild + ทดสอบบนเครื่องเดโม่ก่อน promote ขึ้น production.

ผลกระทบที่เกิดขึ้น

Inspector ภาคสนามใช้ live preview ส่อง seed/fruit หลายชิ้นพร้อมกันเพื่อนับและวัดขนาด. พฤติกรรมเดิมแสดง overlay แค่ลูกเดียวต่อเฟรม ทำให้ inspector ต้องเลื่อนกล้องส่องทีละลูก หรือกดถ่ายภาพ snapshot ทุกครั้ง — ช้าและไม่สมจริงกับ workflow ที่นำเสนอลูกค้า. ภาพ snapshot ใช้งานได้ปกติตลอด จึงไม่กระทบฟีเจอร์ measurement/grading.

สาเหตุที่แท้จริง

iOS โหลด neural-net model ผ่าน Apple CoreML framework. Model ส่ง output มาเป็น tensor 300 ช่อง (3 × 300 = ที่ละ object). Library ที่เราเขียนเองอ่าน tensor นี้แบบ บรรทัดต่อบรรทัด สมมติว่า memory เรียงแบบติดกัน — แต่จริงๆ CoreML จัด memory โดยใส่ padding ช่วงระหว่าง row (เพื่อให้ GPU access เร็ว). ผลคืออ่าน memory ผิดที่ → ได้ค่าขยะที่ดู "เหมือน" detection จริงๆ แต่ค่าผิดเพี้ยน (score มากกว่า 1, class เป็นค่าลบ, bbox อยู่นอกจอ).

ภาพ snapshot ไม่มีปัญหานี้เพราะใช้ Swift code คนละไฟล์ ที่บังเอิญใช้ API ที่ handle padding ถูกต้อง. Live preview ใช้ ObjC++ ใน frame processor — ตัวนี้คือที่บัคซ่อนอยู่.

การไล่หาบัค

  • ตั้งสมมติฐาน #1: Confidence threshold สูงเกิน ลดจาก 0.75 → 0.4 ไม่ช่วย. ทุก threshold มีบัค.
  • ตั้งสมมติฐาน #2: Orientation handling ผิด ทดลองถือเครื่องแนวนอน + แนวตั้ง ผลเหมือนกัน. ลบทิ้ง.
  • ตั้งสมมติฐาน #3: Model ออก output ผิดใน live mode เทรนโมเดลใหม่ + ลองสลับ — ผลเหมือนเดิม. โมเดลไม่ใช่ปัญหา.
  • ตั้งสมมติฐาน #4: Letterbox padding hallucination ใส่ diagnostic probes log ค่าที่ model ส่งออกมาจริงๆ — เห็น garbage pattern ชัดเจน.
  • Root cause พบโดย Codex AI review MLMultiArray strides bug. แก้ด้วย stride-aware memory access. Live multi-detect ใช้งานได้.

บทเรียน

สมมติฐานแรกๆ ทั้งหมด (threshold, orientation, model) ดูสมเหตุสมผลแต่ผิด. จุดเปลี่ยนคือใส่ diagnostic probes log ค่าจริงที่ model ส่งออกมา — ทำให้เห็นว่าค่าที่ได้ "ดูเหมือน" detection แต่จริงๆ เป็นขยะ. หลังจากนั้น Codex AI review code อย่างละเอียดและพบบัคที่ stride access pattern. Library code ที่ใช้กับ Apple CoreML ทุกที่ในแอพควรตรวจสอบว่าใช้ stride-aware access ทุกครั้ง ไม่งั้นจะเจอบัคแบบนี้ซ่อนอยู่อีก.
